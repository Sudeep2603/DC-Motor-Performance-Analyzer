# Usage Guide

This document explains how to install, run, and use the DC Motor Performance Analyzer.

---

## 1. Requirements

The application requires:

- Python 3.10 or newer recommended
- NumPy
- Matplotlib
- Tkinter

Install the required Python packages using:

```bash
pip install -r requirements.txt
```

Tkinter and the `csv` module are normally included with Python.

---

## 2. Start the Application

From the project directory, run:

```bash
python src/motor_performance_analyzer.py
```

The main **Motor Performance Analyzer** window will open.

---

## 3. Main Menu

The application provides three experiments:

- Swinburne's Test
- Load Test on DC Series Motor
- Load Test on DC Shunt Motor

Select the required experiment from the main window.

---

## 4. Swinburne's Test

Click:

**Swinburne's Test**

The program will ask you to select the operating mode.

Available modes are:

- Motor Operation
- Generator Operation

---

## 5. Swinburne's Test Inputs

The program requests the following values:

- Supply Voltage, `VL`
- Field Current, `If`
- No-Load Line Current, `IL0`
- Armature Resistance, `Ra`
- Rated Line Current
- Rated Speed

After entering the values, click:

**Calculate & Plot**

---

## 6. Swinburne's Test Output

For motor operation, the application determines performance values over a range of operating currents.

The generated results include:

- Output Power
- Efficiency
- Speed
- Torque
- Line Current

The program displays these values using a performance-characteristic graph.

For generator operation, the application calculates and plots generator efficiency against output power.

---

## 7. Machine-Life Inference

After performing a test, the application provides qualitative machine-life information.

The program considers:

- Peak operating efficiency
- Rated current
- Operation above rated current

If the calculated operating current exceeds the rated current, the application displays an overload warning.

This feature provides general machine-health insight.

It does not calculate an exact remaining motor lifetime in hours or years.

---

## 8. DC Series Motor Load Test

From the main menu, select:

**Load Test on DC Series Motor**

The program first asks for the number of readings.

The allowed number of readings is between 5 and 15.

The application then requests:

- Brake Drum Radius
- Rated Current

For every reading, enter:

- Voltage
- Current
- Spring Balance Reading `S1`
- Spring Balance Reading `S2`
- Speed

After entering all readings, click:

**Calculate & Plot**

---

## 9. DC Shunt Motor Load Test

Select:

**Load Test on DC Shunt Motor**

The input procedure is the same as the DC Series Motor load test.

Enter:

- Brake Drum Radius
- Rated Current
- Voltage
- Current
- `S1`
- `S2`
- Speed

for the required number of readings.

---

## 10. Load-Test Calculations

The application calculates the following values.

### Input Power

```text
Input Power = Voltage × Current
```

### Force

```text
Force = S1 - S2
```

### Torque

```text
Torque = Force × Drum Radius × 9.81
```

### Output Power

```text
Output Power = (2 × π × Speed × Torque) / 60
```

### Efficiency

```text
Efficiency = (Output Power / Input Power) × 100
```

---

## 11. Load-Test Graphs

The application generates two main graphs.

### Performance Characteristics

The performance-characteristic graph displays quantities such as:

- Efficiency
- Speed
- Torque
- Line Current

against output power.

### Torque-Speed Characteristic

The application also plots:

```text
Speed vs Torque
```

This graph shows how motor speed varies as the load torque changes.

---

## 12. Saving Results

After calculation, the program asks:

```text
Would you like to save these results to a file?
```

Select **Yes** to save the results.

The output is stored as a CSV file.

Depending on the experiment, the saved file may contain values such as:

- Voltage
- Current
- Speed
- Torque
- Efficiency
- Output Power

---

## 13. Sample Result File

A sample DC Shunt Motor load-test result is available in:

```text
data/sample_shunt_load_results.csv
```

This file can be used to understand the format of saved results.

---

## 14. Loading Previous Results

Previously saved results can be loaded from the application.

From the menu bar select:

**File → Load Saved Data**

Select a saved CSV file.

The application reads the data and displays the corresponding graph.

---

## 15. Output Screenshots

Example outputs from the application are available inside:

```text
images/output/
```

The folder contains screenshots such as:


These images demonstrate the GUI and the graphs generated by the program.

---

## 16. Common Input Errors

The application expects numerical values for motor parameters.

If invalid text is entered, an error message will be displayed.

Make sure that:

- All required fields are filled
- Numerical values are entered correctly
- The number of load-test readings is between 5 and 15
- Rated current is entered correctly
- Speed is entered in rpm
- Brake drum radius is entered in metres

---

## 17. Closing the Application

The program can be closed using the normal window close button.

It can also be closed using:

**File → Exit**

---

## Summary

The basic workflow of the application is:

```text
Start Program
      ↓
Select Motor Test
      ↓
Enter Test Data
      ↓
Calculate
      ↓
Plot Characteristics
      ↓
View Machine-Life Insight
      ↓
Save Results
```

The program combines DC machine performance calculations with a graphical interface, plotting, file handling, and Object-Oriented Programming.
